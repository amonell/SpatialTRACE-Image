# Release status

Code is available at [amonell/TissueMapper-Image](https://github.com/amonell/TissueMapper-Image). The repository is private and uses GPL-3.0-only.

The four pretrained models are attached to [v1.0.0rc1](https://github.com/amonell/TissueMapper-Image/releases/tag/v1.0.0rc1). See [download instructions](docs/artifacts.md).

Training, prediction, and CPU/GPU installation have been tested. GitHub Actions runs the CPU tests on each push. See [Tests](VALIDATION.md).
