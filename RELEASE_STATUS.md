# Release status

Code is available at [amonell/SpatialTRACE-Image](https://github.com/amonell/SpatialTRACE-Image). The repository is private and uses GPL-3.0-only.

The four pretrained models are attached to [v1.0.0rc2](https://github.com/amonell/SpatialTRACE-Image/releases/tag/v1.0.0rc2). See [download instructions](docs/artifacts.md).

Training, prediction, and CPU/GPU installation have been tested. GitHub Actions runs the CPU tests on each push. See [Tests](VALIDATION.md).
